# 通用工程踩坑日志

> 记录可复用的技术问题、根因和修复方法。  
> 不记录设备编号、网络地址、账户信息、聊天内容或本机操作历史。

### 2026-10-27: [逻辑] 修复症状不等于修复根因

- **问题**: 同一类错误在多个调用点重复出现。
- **根因**: 修改只覆盖了报错路径，没有处理共享逻辑。
- **解决**: 搜索全部调用方，在共享函数或统一入口增加校验和修复。
- **预防**: 修改前先建立调用链；验证正常路径和兄弟调用路径。

### 2026-10-27: [环境] 脚本编码与换行差异

- **问题**: PowerShell、Python 或其他工具读取脚本时出现语法错误或乱码。
- **根因**: UTF-8 BOM、ANSI 编码和 CRLF/LF 换行处理不一致。
- **解决**: 源文件统一使用无 BOM UTF-8；通过 `.gitattributes` 固定文本和二进制规则。
- **预防**: 在目标运行时中实际执行脚本，不只检查文件内容。

### 2026-10-27: [环境] 本地化命令行输出不适合稳定解析

- **问题**: 脚本按英文标签解析系统命令，在中文系统上失效。
- **根因**: 命令行工具会按系统语言本地化输出。
- **解决**: 优先使用结构化 cmdlet 或 API；无法避免文本解析时使用语言无关字段。
- **预防**: 在非默认语言环境下运行测试。

### 2026-10-27: [工具] 禁用诊断能力会降低可观测性

- **问题**: 程序失败后没有事件日志或转储，难以定位。
- **根因**: 错误报告和诊断服务被关闭，崩溃只留下不可分析的界面提示。
- **解决**: 关闭用户提示前，先建立最小日志、事件或转储采集。
- **预防**: 任何“优化”都要同时评估故障取证能力。

### 2026-10-27: [安全] 配置迁移必须先脱敏

- **问题**: 配置快照可能包含 API Key、OAuth Token、账户标识和本机路径。
- **根因**: 配置文件常把凭据、路由信息和界面设置混在一起。
- **解决**: 使用白名单导出可迁移字段；凭据在新设备上重新授权。
- **预防**: 提交前扫描密钥和隐私关键词，并把导出脚本纳入仓库。

### 2026-10-27: [可靠性] 配置跨设备不能直接复制全部路径

- **问题**: 安装路径、运行时哈希和用户目录在另一台设备上失效。
- **根因**: 配置同时包含声明式 Preferences 和机器专属路径。
- **解决**: 使用占位符和恢复脚本替换当前用户目录；机器生成的运行时配置由目标程序重建。
- **预防**: 恢复前备份原配置，恢复后在目标设备上做实际启动验证。
